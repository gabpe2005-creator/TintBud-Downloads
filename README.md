# TintBud Downloads

Official distribution location for **TintBud Windows desktop** installers and signed application updates.

**Status: not publicly released.** There are no approved installable releases or automatic updates yet. Development builds are not customer-ready.

## Downloads

When the first reviewed release is approved, download the Windows installer from [Releases](https://github.com/gabpe2005-creator/TintBud-Downloads/releases). A new installation is required once; subsequent signed releases can be offered inside TintBud through **Check updates** / **Update & restart**.

## Security and scope

- This repository contains **release artifacts only** (approved Windows installers, signatures, checksums, and updater metadata). Source code stays in the private TintBud development repository.
- Do not upload source code, credentials, signing private keys, customer records, or database backups.
- The update feed is `https://github.com/gabpe2005-creator/TintBud-Downloads/releases/latest/download/latest.json`, and will not work until a verified signed release exists.
- Windows updates are disabled in unconfigured development builds. Installed apps verify signed updater artifacts before installing.
- macOS releases are paused.

Do not install or bypass Windows security warnings for unsigned or unreviewed builds.
